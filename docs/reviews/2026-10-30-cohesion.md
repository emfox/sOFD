# 内聚耦合审查报告

日期：2026-10-30 · 范围：全部 30 个 crate · 方法：分层职责对照 + 公开 API 梳理 + 跨后端语义核对

## 总评

分层结构整体成立：L0→L5 的依赖方向基本干净，testkit 无正式依赖者，session 不认识窗口，门面 re-export 有节制。但审查发现 **1 个真实 bug**（本轮已修）、**4 个结构性错位**（建议排期修）、以及一批低风险问题。最集中的裂缝在 `dst`/`Alpha`/`premultiply` 三个"跨层语义约定"上——它们没有单一权威定义，靠各后端"恰好一致"维持正确。

---

## 一、本轮已修

### 1.1 文本对象的 `Alpha` 被遗漏（真实 bug，已修）

`6b055e2` 修复 `PathObject` 的 `Alpha="0"` 背板时，只覆盖了 `flatten_path`。`flatten_text`（`sofd-parser/src/flatten.rs:590-615`）的 fill/stroke 仍直接来自 `solid()`，未过 `faded()`——一个 `Alpha="0"` 的 `TextObject` 会把文字不透明地画上去。已补 `faded()` 调用与回归测试 `a_text_object_honours_the_object_alpha_as_well`（commit `49c0503`）。

## 二、结构性错位（建议排期）

### 2.1 `sofd-io` 反向依赖 `sofd-display`（L0 依赖 L2）

`sofd-io/src/decode.rs:7` 为一个 `ImageCodec` 枚举把 display→geometry→font→serde 整条链拉进最底层。`ImageCodec` 是"文档里图片怎么存"的格式知识，不是显示语义——应下沉到 io（或 common），由 model/parser 层构造。修掉后 `sofd-io` 回归真正的 L0。

### 2.2 `premultiply` 双向搬运：alpha bug 的结构性温床

`decode` 的两个消费者拿到的是**预乘** RGBA（`decode.rs:28-32`），于是：
- `sofd-render` 的 `rgba_bytes()` 反预乘一次输出（`raster/mod.rs:99-109`）；
- `sofd-convert` 的 `split_alpha` 反预乘一次给 PDF 掩膜（`pdf/content.rs:70-92`）；
- `Pixels::Rgb` 变体在生产代码中已无消费者。

**建议**：`decode` 增加非预乘输出模式（或让 Rgba 变体直接非预乘、加一个 `Premultiplied` 变体给 raster），让"预乘"只发生在 tiny-skia 边界内。这样 `split_alpha` 与 `rgba_bytes` 的反预乘代码都可以删掉，本次修的 SMask 路径少一次有损往返。

### 2.3 glyph→Unicode 反查职责悬空

`sofd-font` 提供 `reverse_cmap`（`face.rs:212`），注释说"供搜索和复制使用"，但**全仓只有测试和 fuzz 调用它**；`sofd-search` 的 `glyph_to_text` 只读 `run.text` + `cluster_map`（`search/lib.rs:200-218`），从不回退到字体反查。结果是：没有 ToUnicode 映射的文档，搜索/复制不出文字——而能力其实已经写好了。**建议**：`search` 在 cluster_map 缺失时回退 `reverse_cmap`，或把反查从 font 挪进 search。

### 2.4 `DrawOp::Image::transform` 是死字段，且四个后端解释分裂

parser 永远传 `IDENTITY`（`flatten.rs:949`），而四个后端：
- raster **忽略**它（`raster/text.rs:144`）；
- vector **忽略**它（`vector.rs:212` 注释明说"applying it again would double it"）；
- SVG **应用**它（`svg.rs:480`）；
- PDF **应用**它（`pdf/mod.rs:575`）。

当前恰好无害，但这是下次"图片位置错"的现成温床。另外 `dst` 的解释也分裂：raster/SVG/vector 走 `dst/像素数`（像素矩形语义），PDF 走 `dst`（放置矩形语义），只因 parser 恒写单位方格而等效。**建议**：要么删掉 `transform` 字段，要么在 display 层用一句话把 `dst`/`transform` 的语义写进 `DrawOp::Image` 的文档注释，并让四个后端对齐。`dst` 语义同样需要一段权威注释。

### 2.5 渐变/网纹/图案在 PDF 后端静默降级为黑色

`pdf/mod.rs:508-526` 非 Solid 填充一律写黑，Pattern 用首色近似（`content.rs:110`），径向渐变用均值缩放（`mod.rs:616`，非等比 CTM 失真）。raster 正确画了这些——**预览与导出不一致**。display IR 承载了 `Mesh`/`Pattern`，但 raster 对 Mesh/Pattern 返回 `None` 静默丢弃（`raster/shape.rs:153`）。IR 承载的每个变体要么有后端实现，要么有显式的"此导出不支持"统计（`ConversionStats` 已有计数字段可扩展），不该是静默黑块。

## 四、低风险（记录在案）

- `sofd/async` feature 实为渲染策略（rayon 批量栅格）而非文档能力；
- `convert`/`pdf` feature 是包含关系，命名像并列；
- 文档过期：`docs/Architecture.md:253` 仍写已删除的 `backend-raster` feature；:264 说门面 "trims nothing" 但 `annot` 实际有门控；
- `sofd-archive::archive()` 提供容器重写但门面只暴露 `audit`，声明与实现矛盾；
- `sofd-i18n` 泄漏 `FluentValue` 类型到调用方签名；
- `sofd-model` 依赖 serde_json 做未知值保底；
- `sofd-edit` 的 dev 测试跳层用门面回读。

## 五、修复次序建议

1. **`ImageCodec` 下沉**（2.1）——一次性解除 L0→L2 反向依赖，改动小；
2. **premultiply 单向化**（2.2）——删两份反预乘代码，alpha 类 bug 的根源就此收口；
3. **`DrawOp::Image` 语义注释 + transform 处置**（2.4）——半小时的文字工作，防患于未然；
4. **glyph→Unicode 回退**（2.3）——已有能力接上就是用户可见的搜索改善；
5. **PDF 渐变降级显式化**（2.5）——先加统计计数，再逐步实现；
6. 其余按便利性吸收进日常改动。

每项都是独立的提交，互不阻塞。
