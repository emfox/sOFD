# every existing clone. They are exempt; anything after this point is not.
#

#
# One short sha and an optional reason per line, `#` starts a comment.
#
# This list is meant to shrink. Each entry is a debt someone accepted, and
# removing an entry is a small celebration.
#
# It is currently empty: every over-long message was rewritten in place, so the
# whole history is clean and nothing needs exempting. CI passes this file either
# way, which is deliberate -- a stale entry must not hide a new violation.
