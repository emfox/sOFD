The Adwaita symbolic SVGs the glyphs in `sofd-icons` were copied from, vendored
so the check does not depend on whichever theme the host ships.

`adwaita-44/` is the release the set started from; icons added later were taken
from `adwaita-51/`. A glyph has to match the file in one of them, re-encoded but
not redrawn. Licence CC BY-SA 3.0 US, drawn by the GNOME Project; see
`NOTICE.md`.
